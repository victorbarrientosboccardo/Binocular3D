# Binocular3D

Sitio de Binocular3D (visor 3D de repuestos para equipos mineros): https://www.binocular3d.com

| Carpeta o archivo | Contenido |
|---|---|
| `index.html`, `privacidad.html`, `terminos.html`, `404.html` | Portada y páginas legales (abiertas) |
| `acceso/` | Portal de acceso con usuario y clave a las versiones Estándar y Plus |
| `acceso/v/` | Versiones cifradas (AES-256-GCM) y `usuarios.json` |
| `acceso/vendor/`, `acceso/fonts/` | Librerías de código abierto y tipografías |

Los usuarios se administran desde el propio portal, con una clave de administrador.
Las licencias de terceros están en `licencias.txt`.
